## Working conventions

- **Sprints are scoped before work begins.** Each sprint has a document in `docs/sprints/` defining goals and acceptance criteria. Do not build outside the current sprint scope without flagging it.
- **No placeholder code.** If a file is created, it contains real content. Stubs and TODOs are allowed only when the surrounding context makes the intent unambiguous.
- **Small commits, clear messages.** One logical change per commit. Messages describe why, not what.
- **Docs live next to decisions.** Architecture choices go in `docs/architecture/`, not inline comments.
