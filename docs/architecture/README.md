## Document format

Each architecture document should cover:

1. **Context** — what problem this addresses and why it matters
2. **Decision** — what was chosen and the key constraints
3. **Alternatives** — what else was considered
4. **Consequences** — what becomes easier or harder as a result

---

*Prefer short, durable decision records over exhaustive specification documents.*
